# Trail Track BI

Power BI dashboard for park visit client booking analytics.

##  Overview
Tracks bookings, visitors, revenue, and trends across parks.

##  Files
- `Trail_Track_BI.pbix` — Main Power BI report file

##  Requirements
- Power BI Desktop 
- Access to the source data model / gateway

##  Getting Started
1. Clone this repo
2. Open `Trail_Track_BI.pbix` in Power BI Desktop
3. Refresh data connections
4. Publish to your Power BI Service workspace

## Dashboard Pages
- Overview (KPIs)
- Bookings
- Visitors
- Revenue
- Trends
- Forecast
